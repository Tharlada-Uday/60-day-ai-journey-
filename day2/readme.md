# Day 2 - Python for Production: Environments & Structure

## Goal

Learn how to organize Python projects professionally and manage project dependencies using virtual environments.

## Topics Covered

- Python virtual environments (`venv`)
- Package management with `pip`
- `requirements.txt`
- `src`-layout project structure
- PEP 8 coding style
- Python type hints
- Python project packaging basics
