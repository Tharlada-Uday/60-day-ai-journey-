## What I Learned

- Git tracks changes in a project.
- Git is a popular cloud platform where can collabrate and  work with different people
- `git add` stages changes.
- `git commit` saves a version in Git history.
- `git push` uploads local commits to GitHub.
-  `git pull` Fetching + Merging 
- `git branch` to  check the branchs 
- `git branch name` to create a branch named name 
- `git checkout name` to move to a branch named name
